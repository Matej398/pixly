# Pixly - Pixel Art Creator

A simple, browser-based pixel art creation tool that allows users to create, save, and export pixel art.

## Features

- Adjustable grid size (up to 100x100)
- Color picker
- Multiple brush sizes
- Drawing tools: Pencil, Fill, Eraser
- Undo/Redo functionality
- Zoom in/out
- Save and load projects (JSON format)
- Export as PNG, JPG, or SVG

## Usage

1. Open `index.html` in your web browser
2. Select your grid size and tools
3. Create your pixel art
4. Save your work or export it in your preferred format
